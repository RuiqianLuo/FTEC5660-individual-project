## 4) Key blockers encountered (and how the agent helped)

### Blocker A — “No valid md tasks / wrong prompt directory”
- Symptom: grader could not find expected task prompt files / output directory mismatches.
- Agent action: searched repo layout to locate where prompts are generated/stored, then updated paths so the run uses the correct prompt directory.

### Blocker B — Windows encoding broke the grader (`gbk` / UnicodeEncodeError)
- Symptom: test script crashed printing JSON output in Windows default encoding.
- Fix: force UTF-8 output in Windows console before running `gittaskbench grade`:
  - `set PYTHONIOENCODING=utf-8`
  - `set PYTHONUTF8=1`

### Blocker C — Dependency/import issues for Excel parsing
- Symptom: `ModuleNotFoundError: openpyxl` and/or inability to import `eparse`.
- Fix:
  - install missing dependency (`openpyxl`)
  - set `PYTHONPATH` to include the local `code_base/Eparse` repo root so Python can import `eparse`.

### Blocker D — Output format mismatch (“0 Excel data blocks found”)
- Symptom: grader reported 0 Excel blocks in the prediction output file.
- Root cause: output text headers/block delimiters did not match what the grader expects.
- Fix: adjust the script output format so each Excel file and sheet is emitted using the expected structure.
